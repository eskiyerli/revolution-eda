# `revedaEditor/backend`

Non-GUI backend: library model, undo commands, loaders, correspondence/connectivity state, project/process management.

## Modules

- [[revedaEditor/backend/LVSModelView|LVSModelView.py]] — Qt table models/views for the LVS results browser (nets, devices, cells, cross-references, parameter mismatches)
- [[revedaEditor/backend/__init__|__init__.py]] — Package marker for the non-GUI backend layer (library model, undo commands, loaders, process/project management)

- [[revedaEditor/backend/dataDefinitions|dataDefinitions.py]] — Shared data types: `edLayer`/`layLayer` dataclasses and the namedtuple records (`viewNameTuple`, `viewItemTuple`, pin/layer defs) exchanged…
- [[revedaEditor/backend/drcModelView|drcModelView.py]] — Qt table model/view pair used to browse KLayout DRC results
- [[revedaEditor/backend/editFunctions|editFunctions.py]] — Shared small widgets (`shortLineEdit`, `boldLabel`, `longLineEdit`); the `gui/editFunctions.py` copy is the actively imported one
